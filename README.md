### ⚙️ How I Think About AI Agents

For me, an agent is more than an LLM generating text.

A useful agent forms a loop:

**Understand → Reason → Choose an Action → Execute → Observe → Adapt → Verify**

My Mini-SWE-Agent project explores this loop directly by giving an LLM access to tools and an execution environment, then feeding the resulting observations back into the agent.

I'm particularly interested in the engineering questions around this loop:

* How should an agent decide which tool to use?
* How should context be constructed and maintained?
* How do we handle failures and recovery?
* How do we know whether an agent actually solved the task?
* How can agentic systems become more reliable?
* How do we evaluate agents beyond a single successful demonstration?

### 🔭 Engineering Philosophy

I prefer understanding systems from first principles rather than relying entirely on abstractions.

For AI systems, that means going beyond:

**Prompt → LLM → Response**

and thinking about:

**Context → Reasoning → Tools → Environment → Observation → Evaluation → Feedback**

My goal is to turn research ideas into working systems and continuously improve their reliability, capability, and evaluation.
