### 🔭 Featured Projects

**[RideFlow](https://github.com/suhanapriya/RideFlow)** — A distributed ride-hailing platform built in Go, modeled on Uber-scale architecture.
- 14 microservices communicating over an async NATS event bus
- Real-time driver tracking via Redis geospatial indexing (Uber's H3 grid)
- Zero-trust security: rotating JWT keys, RBAC, audit logging
- Dockerized, Kubernetes-ready, with a full CI/CD pipeline and 200+ commits

**[LinkSnap](https://github.com/suhanapriya/LinkSnap)** — A production-style URL shortener built with NestJS, PostgreSQL, and TypeORM.
- Custom short links, expiration handling, and click analytics
- Rate limiting via custom decorators and interceptors
- Clean, layered architecture with dependency injection
